## Variables

| Variable                                                                   | Description                                                                                                               |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| [BACKGROUND\_TAG](variables/BACKGROUND_TAG.md)                             | Marks an operation as invocable by the job queue.                                                                         |
| [BACKOFF\_BASE\_MS](variables/BACKOFF_BASE_MS.md)                          | Exponential backoff base delay.                                                                                           |
| [BACKOFF\_FACTOR](variables/BACKOFF_FACTOR.md)                             | Multiplier applied per attempt: base * factor^attempt.                                                                    |
| [BACKOFF\_MAX\_MS](variables/BACKOFF_MAX_MS.md)                            | Cap on scheduled backoff delay (5 minutes).                                                                               |
| [CLAIM\_POLL\_INTERVAL\_MS](variables/CLAIM_POLL_INTERVAL_MS.md)           | Claim-loop backstop poll interval (wake-on-enqueue is the fast path).                                                     |
| [CRON\_TRIGGER\_PREFIX](variables/CRON_TRIGGER_PREFIX.md)                  | Prefix for trigger-map keys that represent cron schedules rather than OpenAPI operationIds (`cron:{jobName}`).            |
| [DEFAULT\_MAX\_ATTEMPTS](variables/DEFAULT_MAX_ATTEMPTS.md)                | Default max delivery attempts before a job goes `dead` / exhausted.                                                       |
| [DEFAULT\_TIMEOUT\_MS](variables/DEFAULT_TIMEOUT_MS.md)                    | Default per-attempt delivery timeout (30s).                                                                               |
| [ERROR\_BODY\_CAP\_BYTES](variables/ERROR_BODY_CAP_BYTES.md)               | Max stored `result.error_body` size (8 KB).                                                                               |
| [GLOBAL\_CONCURRENCY](variables/GLOBAL_CONCURRENCY.md)                     | Max concurrent in-flight deliveries in one runtime process.                                                               |
| [HEARTBEAT\_INTERVAL\_MS](variables/HEARTBEAT_INTERVAL_MS.md)              | Interval for refreshing `heartbeat_at` while a delivery is in flight.                                                     |
| [jobsServiceStorage](variables/jobsServiceStorage.md)                      | -                                                                                                                         |
| [REQUEST\_SIZE\_CAP\_BYTES](variables/REQUEST_SIZE_CAP_BYTES.md)           | Max serialized `request` JSON size (16 KB).                                                                               |
| [RETENTION\_MS](variables/RETENTION_MS.md)                                 | How long terminal jobs are retained before deletion (30 days).                                                            |
| [RETENTION\_SWEEP\_INTERVAL\_MS](variables/RETENTION_SWEEP_INTERVAL_MS.md) | How often the runtime deletes terminal jobs older than retention.                                                         |
| [SPAWN\_CAP](variables/SPAWN_CAP.md)                                       | Max jobs allowed per `original_request_id` (spawn cap).                                                                   |
| [STALL\_GRACE\_MS](variables/STALL_GRACE_MS.md)                            | Extra time beyond the operation timeout before a stale `heartbeat_at` is treated as a stalled delivery (timeout + grace). |
| [STALL\_RECOVERY\_INTERVAL\_MS](variables/STALL_RECOVERY_INTERVAL_MS.md)   | How often the runtime runs stall recovery (also runs once at startup).                                                    |
| [TIMEOUT\_CEILING\_MS](variables/TIMEOUT_CEILING_MS.md)                    | Ceiling for per-operation `timeoutMs` overrides (120s).                                                                   |

## Functions

| Function                                                        | Description                                                                                                                                                                                                                        |
| --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [buildOperationMap](functions/buildOperationMap.md)             | Walk a bundled OpenAPI document and map every `operation_id` to its HTTP method, path template, and whether it carries the `background` tag.                                                                                       |
| [createJobsApp](functions/createJobsApp.md)                     | Express app for the jobs internal surface (enqueue only). Host with `startExpressServer(app, { socketPath })` so requests are markInternal'd and assertion auth applies.                                                           |
| [createJobsRouter](functions/createJobsRouter.md)               | Admin jobs router for monolith chrome (list/get/cancel-by-chain). Only handles `/jobs/*` — other paths fall through so sibling chrome routers (e.g. cron) can run. Error middleware is scoped to `/jobs` for the same reason.      |
| [cronTriggerKey](functions/cronTriggerKey.md)                   | Trigger-map / assertion callingOperationId for a cron job name.                                                                                                                                                                    |
| [enqueue](functions/enqueue.md)                                 | Enqueue a background job under the current request's acting user. Derives callingOperationId / originalRequestId from `getSafContext()`.                                                                                           |
| [enqueueOnBehalfOf](functions/enqueueOnBehalfOf.md)             | Enqueue under an explicit user + authority evidence (webhooks, etc.).                                                                                                                                                              |
| [isCronTriggerKey](functions/isCronTriggerKey.md)               | True when a trigger-map key is a cron schedule source (`cron:{jobName}`).                                                                                                                                                          |
| [makeCronEnqueuer](functions/makeCronEnqueuer.md)               | Factory for the enqueue function injected into `@saflib/cron-http`. Signs with `callingOperationId = cron:{jobName}` and passes `on_behalf_of` cron authority for the enabling admin. Does not import `@saflib/cron-http`.         |
| [mapJobToWire](functions/mapJobToWire.md)                       | Maps a jobs-db row to the wire `Job`: date fields → ISO strings, omit heartbeat/updated_at, and strip the embedded enqueue assertion from authority.                                                                               |
| [runJobs](functions/runJobs.md)                                 | Start the jobs claim loop, delivery workers, and periodic sweeps. Validates the trigger map / operation config against `apiSpec` at startup.                                                                                       |
| [signalJobsWake](functions/signalJobsWake.md)                   | Signal the running jobs runtime to claim immediately (no-op if none running). Enqueue handlers call this after a successful create.                                                                                                |
| [validateCronTriggerKeys](functions/validateCronTriggerKeys.md) | Product-side check: every `cron:` trigger-map key names a registered cron job, and every registered cron job has a `cron:` trigger-map entry. Call at service startup with `Object.keys(jobsMap)` (no `@saflib/cron-http` import). |
| [validateJobsStartup](functions/validateJobsStartup.md)         | Startup validation for the trigger map and per-operation config. Throws on unknown ids, missing `background` tags, or timeout ceiling breaches.                                                                                    |
