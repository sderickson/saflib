## Functions

| Function                                                                          | Description                                                                                                                                                                                                                                  |
| --------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [configureAuthApp](functions/configureAuthApp.md)                                 | Call once from the auth shell (e.g. `AuthApp.vue`) to provide options for nested Kratos pages, including post-auth, post-register, and logged-out root URLs.                                                                                 |
| [defaultPostRecoverySettingsHref](functions/defaultPostRecoverySettingsHref.md)   | Default recovery → settings continue URL (auth `/settings?flow=…`). Override via [configureAuthApp](functions/configureAuthApp.md) `postRecoverySettingsHref` when settings live on another SPA (e.g. account).                              |
| [useAuthAppConfig](functions/useAuthAppConfig.md)                                 | -                                                                                                                                                                                                                                            |
| [useAuthLoggedOutRootFallbackHref](functions/useAuthLoggedOutRootFallbackHref.md) | After logout: when the shell set `rootHomeOverrideHref`, that URL is used and `?return_to=` is ignored. Otherwise `?return_to=` wins, then the resolved default URL.                                                                         |
| [useAuthOnBeforeLogout](functions/useAuthOnBeforeLogout.md)                       | Optional host callback to run before Kratos browser logout.                                                                                                                                                                                  |
| [useAuthPostAuthFallbackHref](functions/useAuthPostAuthFallbackHref.md)           | After login / post-auth: when the shell set `postAuthOverrideHref`, that URL is used and `?return_to=` is ignored. Otherwise `?return_to=` wins when present, then the resolved fallback URL (`postAuthFallbackHref`, else library default). |
| [useAuthPostAuthUrlIsOverride](functions/useAuthPostAuthUrlIsOverride.md)         | -                                                                                                                                                                                                                                            |
| [useAuthPostRecoverySettingsHref](functions/useAuthPostRecoverySettingsHref.md)   | Where recovery should send the browser for a Kratos settings continue step.                                                                                                                                                                  |
| [useAuthPostRegisterFallbackHref](functions/useAuthPostRegisterFallbackHref.md)   | After registration: when the shell set `postRegisterOverrideHref`, that URL is used and `?return_to=` is ignored. Otherwise `?return_to=` wins, then the resolved default URL.                                                               |
| [useAuthPostRegisterUrlIsOverride](functions/useAuthPostRegisterUrlIsOverride.md) | -                                                                                                                                                                                                                                            |
