# Function: isVueSfc()

> **isVueSfc**(`source`): `boolean`

True when `source` looks like a Vue SFC (script + template, or `<script setup>`).
Used by path-agnostic blob parsing where the filename is not available.

## Parameters

| Parameter | Type     |
| --------- | -------- |
| `source`  | `string` |

## Returns

`boolean`
