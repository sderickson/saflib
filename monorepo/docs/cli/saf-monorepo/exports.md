# saf-monorepo exports

```
Usage: saf-monorepo exports [options] [command]

Generate or verify package.json exports maps from directory structure

Options:
  -h, --help          display help for command

Commands:
  generate [options]  Write heuristic exports map into package.json (refuses
                      WORKFLOW AREA packages)
  check [options]     Verify committed exports match heuristic generation; exit
                      1 on mismatch
```
