# saf-monorepo renovate-preset

```
Usage: saf-monorepo renovate-preset [options]

Generate saflib's Renovate presets for product repos (renovate/product.json
turns off every package saflib owns). Run from saflib's root; --check fails if
they're out of date.

Options:
  --check     only report whether the presets are up to date
  -h, --help  display help for command
```
