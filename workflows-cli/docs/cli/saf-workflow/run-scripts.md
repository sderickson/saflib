# saf-workflow run-scripts

```
Usage: saf-workflow run-scripts [options] <path-or-id> [args...]

Run a workflow in script mode. Can be called with a workflow ID or a file path
   to a workflow definition.

Arguments:
  path-or-id  Workflow ID or path to workflow file
  args        Arguments for the workflow

Options:
  -h, --help  display help for command
```
