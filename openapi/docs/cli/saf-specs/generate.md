# saf-specs generate

```
Usage: saf-specs generate [options]

Generate OpenAPI types, JSON bundle, and per-operation/schema fragments

Options:
  -f, --file <file>   OpenAPI spec file path (default: "./openapi.yaml")
  -o, --output <dir>  Output directory (default: "./dist")
  -h, --html          Deprecated: HTML docs are served by @saflib/dev-site
                      (ignored)
  --help              display help for command
```
