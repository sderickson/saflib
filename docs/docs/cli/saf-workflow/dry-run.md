# saf-workflow dry-run

```
Usage: saf-workflow dry-run [options] <path-or-id> [args...]

Dry run a workflow. Runs the workflow with the given input, but does not make
   any file changes at all.

Arguments:
  path-or-id  Workflow ID or path to workflow file
  args        Arguments for the workflow

Options:
  -h, --help  display help for command
```
