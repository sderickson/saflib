# Function: listExportableFiles()

> **listExportableFiles**(`pkgDir`): `string`[]

List exportable source files: all `.ts`/`.tsx` under the package directory
(recursive). Excludes tests, fixtures, bin, docs, workflows, and `env.ts`.

| Parameter | Type     |

| `pkgDir`  | `string` |
