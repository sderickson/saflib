# saf-imports spa

```
Usage: saf-imports spa [options] [command]

Analyze and measure SPA client route bundles

Options:
  -h, --help             display help for command

Commands:
  analyze [options]      Parse router.ts and *Async.vue lazy boundaries (no
                         build)
  measure [options]      Measure shell + per-route page chunks from vite
                         manifest
  measure-all [options]  Measure all gate SPAs
  list-routes [options]  Print route catalog lines for one SPA
  help [command]         display help for command
```
