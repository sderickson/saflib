# saf-imports cycles

```
Usage: saf-imports cycles [options]

Detect circular dependencies in the first-party import graph

Options:
  --package <name>  Limit detection to files in one workspace package
  --include-types   Include type-only imports in the graph
  --root <dir>      Monorepo root (default: auto-detect from cwd)
  -h, --help        display help for command
```
