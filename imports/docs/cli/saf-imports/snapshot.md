# saf-imports snapshot

```
Usage: saf-imports snapshot [options] [command]

Generate or check an import-graph metrics snapshot

Options:
  -h, --help          display help for command

Commands:
  generate [options]  Measure all *.test.ts files, entry probes, and optional
                      timings/bundles
  check [options]     Compare current graphs to a saved snapshot; report
                      regressions
```
