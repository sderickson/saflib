# CI and `import-graph:check`

PathClerk runs import-graph enforcement in GitHub Actions via `npm run import-graph:check` (see root
`package.json`). The check chains several `saf-imports` subcommands.

## What runs today

```bash
npm run import-graph:check
```

| Step | Command | Mode | On failure |
| --- | --- | --- | --- |
| Budget | `saf-imports budget` | optional (`importBudget` per package) | only if limits declared |
| Baseline diff | `saf-imports baseline diff` | **warn** (M9 → error) | exit 0 today |
| Exports | `saf-imports exports check --package …` × 5 | **error** | exit 1 |

Hybrid-pattern packages checked in CI:

- `@pathclerk/daemon-db`
- `@pathclerk/daemon-sdk`
- `@pathclerk/daemon-service-common`
- `@pathclerk/daemon-clients-common`
- `@pathclerk/daemon-forms`

## Fixing regressions

### Import graph grew (baseline diff)

1. Run locally: `npm run import-graph:check` and read the regression list.
2. Use `saf-imports why <test-file> <suspect-module>` to find the new path.
3. Prefer **removing** unnecessary imports (deep imports, slim harnesses) over raising budgets.
4. If the growth is intentional, refresh `daemon/plans/notes/2026-08-07-test-import-graph/baseline.json`
   (or the probes in root `package.json` → `safImports.baseline`).

### `importBudget` exceeded (only if you opted into per-package limits)

Per-package `importBudget` in `package.json` is **optional** and not used in default CI. If you add limits:

1. Run `npm exec saf-imports budget --mode error` locally.
2. Fix imports or slim test setup; only raise limits when the graph is correct but larger.
3. See measured costs: `node saflib/imports/scripts/generate-import-budgets.mjs` (report table).

### Exports pattern uncovered

1. Run `npm exec saf-imports exports check --package <name>`.
2. Add a wildcard pattern or `exportsAliases` entry in `package.json` (see [05-scaffold.md](./05-scaffold.md)).
3. Internal files (`schema.ts`, `testing/` dirs) are excluded from coverage — do not export them.

### SPA shell budget regression

Shell gzip JS is compared in `baseline diff`. Route-level page chunks are **warn-only** until nested-route
measurement matures. See [06-spa-bundles.md](./06-spa-bundles.md).

## Before opening a PR

- [ ] `npm run import-graph:check` passes locally
- [ ] No new root-barrel imports (`@pathclerk/daemon-sdk`, deleted `daemon-clients-common` root, etc.)
- [ ] New workspace packages have `sideEffects` and pattern `exports` (from init templates)
- [ ] Heavy new SPA routes: consider `node saflib/imports/scripts/update-baseline-bundles.mjs`

## M9 error mode (planned)

When flipped, `baseline diff --mode error` will exit 1 on graph/shell regression. Per-package
`importBudget` enforcement remains optional — not part of default CI.
