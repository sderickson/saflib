# saf-deploy status

```
Usage: saf-deploy status [options]

Show which production images would be built, pulled from the registry, or are up
to date.

Options:
  --platform <platforms>  amd64, arm64, native, os/arch, or a comma-separated
                          list (default: SAF_DEPLOY_PLATFORMS from env.remote,
                          else amd64)
  -h, --help              display help for command
```
